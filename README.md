# Flâsh Pro

Flâsh Pro သည် animated cartoon UI ပါသော chat/web app ဖြစ်သည်။ Gemini, Groq, DeepSeek, OpenAI/ChatGPT, xAI/Grok နှင့် Manus Agent ကို အသုံးပြုသူတစ်ဦးချင်းစီ၏ ကိုယ်ပိုင် API key ဖြင့် သုံးနိုင်သည်။

## ပါဝင်သောအင်္ဂါရပ်များ

- AI chat — provider တစ်ခုစီအတွက် ကိုယ်ပိုင် key၊ Enter ဖြင့်ပို့ခြင်း
- Search Friends — Private Chats inbox မှ သီးခြားစာမျက်နှာ
- Private chat နှင့် Group chat — Socket.IO real-time messaging
- Video downloader — server ပေါ်က yt-dlp ကို အသုံးပြုပြီး YouTube, TikTok နှင့် Facebook public video များကို ဒေါင်းလုဒ်လုပ်ခြင်း
- Music library — audio upload, playback, delete; Supabase Storage ကို ရွေးချယ်အသုံးပြုနိုင်ခြင်း
- Cartoon animation — nav, cards, buttons, message bubbles, modals နှင့် forms တစ်လျှောက် motion; reduced-motion preference ကို လေးစားသည်

## စတင်အသုံးပြုခြင်း

လိုအပ်ချက်: Node.js 20+ နှင့် Supabase project တစ်ခု။

```bash
npm ci
cp .env.example .env
# .env ထဲရှိ Supabase နှင့် production secrets များ ဖြည့်ပါ
npm start
```

Production တွင် `SESSION_SECRET` ကို ခန့်မှန်းမရသော random secret ဖြင့် မဖြစ်မနေ သတ်မှတ်ပါ။ Production မှာ မသတ်မှတ်ထားလျှင် server စမည်မဟုတ်ပါ။ `.env` ကို Git ထဲ မတင်ပါနှင့်။

## Supabase ပြင်ဆင်မှု

Server-side operation များအတွက် `SUPABASE_SERVICE_ROLE_KEY` ကို သတ်မှတ်ပြီး server environment ထဲမှာသာ သိမ်းပါ။ ၎င်းကို browser/frontend code ထဲ ဘယ်တော့မှ မထည့်ပါနှင့်။ Supabase မှာ အောက်ပါ column များ ပါသော table သုံးခု လိုအပ်သည်။

```sql
create table if not exists public.users (
  username text primary key,
  password text not null
);

create table if not exists public.settings (
  key text primary key,
  value text not null
);

create table if not exists public.music (
  id bigint generated by default as identity primary key,
  title text not null,
  file_url text not null,
  uploader text not null,
  folder text not null default 'General'
);
```

`settings` မှာ AI key များကို username နဲ့ provider အလိုက် သီးခြား key အဖြစ် သိမ်းသည်။ API key value များကို app က `SESSION_SECRET` မှ ဆင်းသက်လာသော AES-256-GCM key ဖြင့် encrypt လုပ်ပြီး သိမ်းသည်။ `SESSION_SECRET` ပြောင်းလိုက်လျှင် ယခင် encrypt လုပ်ထားသော API key များကို ပြန်ဖတ်မရတော့ပါ။

ယခင် app မှ shared `gemini_key` နှင့် `groq_key` rows များကို app အသစ်က မဖတ်တော့ပါ။ Backup လုပ်ပြီးနောက် database admin က မလိုအပ်တော့သော shared key rows များကို ကိုယ်တိုင်ဖယ်ရှားနိုင်သည်။

RLS ကို ဖွင့်ထားပြီး `service_role` key ကို server-side တွင်သာ အသုံးပြုပါ။ `anon` access ကို table များအတွက် အများသုံး read/write မဖွင့်ပါနှင့်။ Existing Supabase project တွင် RLS policy/schema ကွဲပြားနေပါက server log နှင့် API response တွင် database error ပြန်စစ်ပါ။

### Music storage

`SUPABASE_STORAGE_BUCKET` ကို သတ်မှတ်ထားလျှင် audio ကို Supabase Storage ထဲတင်ပြီး public URL ကို `music.file_url` တွင် သိမ်းသည်။ Environment variable ကိုဖွင့်မီ Supabase Dashboard မှ bucket ကို ဖန်တီးပြီး audio playback အတွက် public read ကိုခွင့်ပြုပါ။ Bucket မသတ်မှတ်ပါက `public/uploads/` ထဲတွင် local disk သိမ်းသည်။ Local disk သည် ephemeral hosting မှာ restart/redeploy ပြီးလျှင် ပျောက်နိုင်သောကြောင့် production အတွက် Supabase Storage ကို အသုံးပြုပါ။

## AI provider များ

အသုံးပြုသူက Settings တွင် provider တစ်ခုစီ၏ ကိုယ်ပိုင် API key ကို ထည့်ရသည်။ Key များကို browser ထံ ပြန်မပို့ပါ။ API key အလုပ်မလုပ်ပါက key ကိုဖယ်ရှားပြီး မှန်ကန်သော key ဖြင့် ပြန်ထည့်ပါ။

Provider အလိုက် default model များကို environment variable ဖြင့် ပြောင်းနိုင်သည်။

- Gemini: `GEMINI_MODEL` (default `gemini-2.5-flash`)
- Groq: `GROQ_MODEL` (default `openai/gpt-oss-120b`)
- DeepSeek: `DEEPSEEK_MODEL` (default `deepseek-flash`)
- OpenAI/ChatGPT: `OPENAI_MODEL` (default `gpt-4.1-mini`)
- xAI/Grok: `XAI_MODEL` (default `grok-4.7`)
- Manus: `Manus Agent` ရွေးချယ်မှုသည် plain model inference မဟုတ်ပါ။ အသုံးပြုသူ၏ Manus API key ဖြင့် private task conversation တစ်ခုဖန်တီးပြီး ဆက်လက်အသုံးပြုသည်။

ChatGPT account subscription နဲ့ OpenAI API access/key သည် သီးခြားဖြစ်နိုင်သည်။ Provider တစ်ခုစီတွင် သက်ဆိုင်ရာ API access ရှိသော key ကို ထည့်ပါ။

## Video downloader

Downloader သည် YouTube, TikTok နှင့် Facebook public video link များကို server ပေါ်က `yt-dlp` ဖြင့် စစ်ဆေးပြီး download လုပ်ပေးသည်။ Railway deployment အတွက် root `Dockerfile` က Python, `yt-dlp[default]` နှင့် FFmpeg ကို install လုပ်ပေးသည်။ `COBALT_API_URL` သို့မဟုတ် သီးခြား downloader API key မလိုပါ။ Download ဖိုင်တစ်ခုလျှင် 500 MB အထိသာဖြစ်ပြီး၊ platform အလိုက် bot detection သို့မဟုတ် access restriction ရှိလျှင် public link တချို့ မရနိုင်ပါ။

## အရေးကြီးသည့် runtime မှတ်ချက်များ

- Session store သည် မူလအားဖြင့် Express memory store ဖြစ်သည်။ App restart လုပ်လျှင် login session များ ပြန်ဝင်ရနိုင်သည်။ Production scale အတွက် persistent session store ချိတ်ဆက်ပါ။
- Chat message history သည် memory ထဲတွင် နောက်ဆုံး 100 ခုပဲ ရှိသည်။ App restart ပြီးလျှင် history ရှင်းသွားမည်။
- Private-chat inbox မှာ မကြာသေးမီက စကားပြောခဲ့သော username များကို browser localStorage ထဲတွင် account အလိုက်သိမ်းသည်။
- `npm run check` သည် server/client JavaScript syntax ကိုစစ်သည်။ Local HTTP smoke test လည်းပြုလုပ်ထားသော်လည်း credential ပါဝင်သော provider end-to-end test များ မပါဝင်သေးပါ။
